Intellectual Property (IPR)

This document describes the intellectual property components incorporated in the ToDrinQ Decision Support Tool (DST).

Foreground and background refer to the scope of the whole ToDrinQ project, not whether a component is developed in this repository or installed separately. Project-created results are foreground IP; pre-existing third-party components are background IP. These descriptions do not assign or transfer ownership: rights holders and access rights are determined by the applicable project agreements and contribution provenance.

Background Intellectual Property

Background IP includes pre-existing code, models, and other material incorporated into the project. Third-party components retain their own licences and copyright notices; the DST’s EUPL licence does not replace those notices.

Foreground Intellectual Property

Foreground IP comprises intellectual property created within the ToDrinQ project, including the NTUA packages and original DST contributions.

pystimela and pystimela_optim

  • Description: Water treatment modelling and process optimization packages

  • Versions included: pystimela 0.0.2, pystimela_optim 0.1.2

  • Developed by: Researchers at the National Technical University of Athens (NTUA), within the scope of ToDrinQ

  • Classification: Foreground IP of the ToDrinQ project, even though packaged separately from the DST

  • Distribution licence: EUPL v. 1.2

  • Public repositories: pystimela and pystimela_optim

  • Distribution: Publicly available from Bitbucket; pre-built wheels are also included in whl/. The packages are not available on PyPI.

Original DST contributions

Original project contributions include:

  • Treatment technology models and scientific assumptions

  • Drinking water quality simulation and decision-support algorithms

  • Cost optimization and resource management frameworks

  • Web application interfaces and REST API implementations

  • Database schema and treatment plant configuration datasets

  • Test suites, validation frameworks, and documentation

  • All original Python, HTML, CSS, and JavaScript code

The provenance of the scientific models and datasets currently in this repository has been checked. Repeat the provenance and rights review for future additions or material changes. The repository carries a KWR Water Research Institute copyright notice and is licensed under EUPL v. 1.2 (see LICENSE).

Guidelines for Contributors

When contributing to this project, please note:

  • Foreground IP: Identify new project-created contributions and their contributors. Contributions are accepted under EUPL v. 1.2; this does not transfer copyright or reclassify pre-existing material as foreground IP.

  • Background IP: If you incorporate any third-party code or models:

    • Verify that the source license is compatible with EUPL v. 1.2

    • Include proper attribution and licensing information

    • Document the provenance in your pull request

    • Do not include proprietary, confidential, or restricted-license materials

  • Scientific Data and Models: Provide clear documentation of:

    • Sources and equations

    • Units, assumptions, and applicability limits

    • Reproducible test cases and expected outputs

    • Any data licensing or attribution requirements

See CONTRIBUTING.rst for the full contribution policy.
