ToDrinQ Decision Support Tool (DST)

The ToDrinQ DST helps water utilities design drinking water treatment trains. A user answers a short series of questions about the source water and the treatment technology preferences. The tool then proposes treatment options, calculates technical, financial and environmental indicators (KPIs) for each option, and lets the user compare the results.

The tool is a Django web application with a REST API. Optionally, selected treatment processes can be optimised with pystimela models using the pystimela_optim package.
