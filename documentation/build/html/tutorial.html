Tutorial

This walk-through creates one design and compares it with a second one.

  1. Log in. Open the start page and log in. Ask an administrator for an account if you do not have one.

  2. Start a design. Start a new design from the menu, enter a name and select the water source.

  3. Answer the questions. Each answer leads to the next question. After the last question, the tool lists the treatment options.

  4. Narrow down the options. Pick a technology in one or more stage dropdowns. The list shows only the options that contain that technology.

  5. Name an option. Enter a name for an option you want to keep. The tool creates a treatment plant for it. Repeat for other options.

  6. Enter the design parameters. Fill in the population, water use, leakage and peak factor, and the financial assumptions. Defaults are filled in for you.

  7. Review the technology properties. Change the values that you know, for example a volume or a dose. Leave the others at their defaults.

  8. Calculate. Press Calculate. The page reports how many properties and KPI values were updated. Press Optimize instead to run the optimiser for the supported processes. The run continues in the background.

  9. Read the results. The results page shows plant KPIs and the KPIs per technology. Download them with the CSV export.

  10. Compare. Open Compare treatment KPIs and select two designs.

Repeat steps 6 to 8 after changing an input. The tool recalculates from the saved values.
